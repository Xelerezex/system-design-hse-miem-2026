# Задание
## 1. Отсев
| Элемент backlog                              | Решение | Причина                                                                                                                  |
| -------------------------------------------- | ------: | ------------------------------------------------------------------------------------------------------------------------ |
| Громкий звонок                               |     MVP | Базовая функция дверного звонка                                                                                          |
| Настройка Wi-Fi через временный Wi-Fi host   |     MVP | Без этого устройство нельзя подключить                                                                                   |
| Push при нажатии кнопки                      |     MVP | Основной пользовательский сценарий                                                                                       |
| Двусторонний аудиозвонок после подтверждения |     MVP | Нужно для общения с курьером                                                                                             |
| Видео после подтверждения                    |     MVP | Нужно видеть посетителя                                                                                                  |
| Смена пароля по текущему Wi-Fi               |     MVP | Базовая безопасность                                                                                                     |
| Motion detection через облако                |    MVP+ | Нужно для охраны, но тяжелее по нагрузке                                                                                 |
| Запись видео/аудио при движении              |    MVP+ | Нужна подписка/хранилище                                                                                                 |
| Громкая сирена из приложения                 |   Later | Не критично для первого релиза                                                                                           |
| 24/7 continuous recording                    |   Later | Слишком дорогой трафик: при 25.327 млн устройств и 2 Mbps ≈ 50.65 Tbps / 547 PB в сутки; расчёт от Ring/Nest 2 Mbps [^1] |

## 2. Scope Refinement
| Зона                 | Входит в scope                                                                                  | Не входит в scope                     |
| -------------------- | ----------------------------------------------------------------------------------------------- | ------------------------------------- |
| Устройство           | Wi-Fi client/host, кнопка, звонок, камера, микрофон, speaker                                    | Собственная ML-модель на устройстве   |
| Мобильное приложение | Настройка Wi-Fi, получение push, подтверждение звонка/движения, просмотр live video/audio       | Социальные функции, шаринг видео      |
| Backend              | Регистрация устройств, push, auth, управление сессиями, WebRTC/stream relay, запись event video | Полноценная система умного дома       |
| Security             | TLS, пароли, токены устройств, запрет неавторизованного доступа к видео                         | Интеграция с полицией/третьими лицами |
| Storage              | Хранение только event-based записей                                                             | Постоянная 24/7 запись в MVP          |

| Compatibility | Wi-Fi                              | Ring Video Doorbell: 802.11 b/g/n 2.4 GHz Wi-Fi [^2]                                        |

## 5. Ограничения
| Ограничение                                   | Что значит для архитектуры                                                              |
| --------------------------------------------- | --------------------------------------------------------------------------------------- |
| Wi-Fi может быть либо host, либо client       | Нужен отдельный setup mode; при reset/button устройство временно выходит из normal mode |
| Setup Wi-Fi host незащищённый                 | Передавать только минимальные bootstrap-данные; сразу менять admin password             |
| Видео идёт через web service                  | Нужен stream ingress / relay / media service                                            |
| Audio two-way через web service               | Нужен low-latency media path, не обычный REST                                           |
| Button press interrupt                        | Событие кнопки должно обрабатываться локально даже при проблемах сети                   |
| Ring sounds лежат в ROM                       | Backend не нужен для самого звука звонка                                                |
| Маленькая reset/setup-кнопка нажимается иглой | Использовать для принудительного перехода в setup mode                                  |

## 6. Расчёт нагрузки

### Метрики

| Исходная метрика                                         |                               Значение |
| -------------------------------------------------------- | -------------------------------------: |
| Владельцы видеодомофонов / видеозвонков в США            |                          58.9 млн [^9] |
| Доля Ring как основного бренда камер/систем безопасности |                               43% [^9] |
| Расчётная база DingDong на масштабе Ring                 | 58.9M × 43% = **25.327 млн устройств** |
| Обычная активность у двери                               |           13–16 events/device/day [^6] |
| Высокая активность у двери                               |           25–30 events/device/day [^6] |
| Максимальная длительность записи события                 |                        до 120 sec [^5] |
| Битрейт видеопотока                                      |                     2 Mbps/device [^2] |
| Максимальный размер push-уведомления                     |                        4096 bytes [^7] |

| Расчёт                                          | Формула                                    |                           Результат |
| ----------------------------------------------- | ------------------------------------------ | ----------------------------------: |

| Средняя нагрузка событий при обычной активности | событий в сутки / 86 400                   |           **3 811–4 690 событий/с** |
| Событий в сутки при высокой активности          | 25.327 млн × 25–30                         | **633.18–759.81 млн событий/сутки** |
| Средняя нагрузка событий при высокой активности | событий в сутки / 86 400                   |           **7 328–8 794 событий/с** |
| Объём видео на одно событие                     | 2 Мбит/с × 120 с / 8                       |                   **30 МБ/событие** |
| Суточный объём видео при обычной активности     | обычные события × 30 МБ                    |             **9.88–12.16 ПБ/сутки** |
| Суточный объём видео при высокой активности     | события при высокой активности × 30 МБ     |            **19.00–22.79 ПБ/сутки** |
| Средняя полоса видео при обычной активности     | событий/с × 120 с × 2 Мбит/с               |             **914.6–1125.6 Гбит/с** |
